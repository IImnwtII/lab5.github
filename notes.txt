Заметки по лабораторной работе № 5

Тема: Организация репозитория в системе управления версиями Git.

Основные понятия:
1. Git — система контроля версий, позволяющая отслеживать изменения файлов.
2. Репозиторий — место хранения файлов проекта и истории их изменений.
3. Коммит — сохранённая версия изменений.
4. Ветвь — отдельная линия разработки проекта.
5. Слияние — объединение изменений из разных ветвей.
6. GitHub — онлайн-платформа для хранения репозиториев и совместной работы.

Основные действия:
- Создание репозитория.
- Добавление файлов.
- Сохранение изменений с помощью коммитов.
- Создание новых ветвей.
- Объединение ветвей.
- Копирование внешнего репозитория с помощью Fork.

Вывод:
Git и GitHub помогают организовывать работу над проектами, хранить историю изменений и управлять различными версиями файлов.
