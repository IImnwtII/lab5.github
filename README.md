# lab5.github
Знакомство с GitHub

## Описание проекта

Данный репозиторий создан для выполнения лабораторной работы № 5 по дисциплине «Информатика» на тему «Организация репозитория в системе управления версиями Git».

## Цель работы

Получить практические навыки работы с системой контроля версий Git и платформой GitHub.

## Содержание репозитория

- `README.md` — описание репозитория.
- `about.txt` — информация о проекте и его назначении.
- `notes.txt` — заметки по основным понятиям Git и GitHub.
- `index.html` — учебный HTML-файл.
- Другие файлы — дополнительные материалы для выполнения лабораторной работы.

## Выполняемые задания

1. Создание репозитория на GitHub.
2. Загрузка файлов и сохранение изменений.
3. Создание трёх ветвей.
4. Объединение ветвей.
5. Создание форка внешнего репозитория.
6. Работа с индивидуальным проектом и публикация сайта через GitHub Pages.

## Результат

Репозиторий используется для изучения основных возможностей Git и GitHub, управления версиями файлов и организации работы над проектами.
